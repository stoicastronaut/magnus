# Agent Studio as a Separate Product Area

Magnus will treat Agent Studio as a separate product area from normal Chats, as a working direction for future multi-agent functionality. Reusing the Chat screen would be faster initially, but Agent Workflows and Agent Loops need room for distinct interaction patterns, state boundaries, Provider and Model assignment per Agent, and future tool scoping. This decision should guide architecture without locking in the final Agent Studio UI or execution model yet.
