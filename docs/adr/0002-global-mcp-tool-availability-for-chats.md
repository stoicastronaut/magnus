# Global MCP Tool Availability for Chats

Magnus makes MCP Tools from Connected MCP Servers globally available to all Chats during the current runtime. This keeps MCP useful in the current Chat flow without adding per-chat tool assignment UI or persistence, while Tool Call results remain scoped to the Chat that invoked them and are not shared with other Chats by default. Future Agent flows may use a different, agent-scoped tool model because Agents can have distinct roles, Providers, Models, and permissions.
